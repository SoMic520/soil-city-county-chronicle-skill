# 市县级识别、模板差异与章节映射

## 1. 先判成果层级，不按地名后缀猜测

项目层级使用两个互斥值：`municipal`＝市级成果，`county`＝县级成果；证据不足或冲突时为`unknown`。县级市名称同样以“市”结尾，所以“××市土壤”只能作为弱线索，不能单独确定为市级成果。

证据优先级从高到低为：

1. 用户或有权责任方明确说明成果层级，并可定位到任务书、合同、正式通知或验收清单；
2. 正式适用导引或模板明确写明“市级成果”或“县级成果”；
3. 正文存在稳定的层级特征，例如市级材料要求核验所辖县级成果、县际接边和市级制图综合；
4. 行政区划名称、文件名和目录名，仅作为辅助线索。

自动识别输出是预判，不替代项目确认。检测结果为`unknown`时，可以继续资料盘点、版本核验和共享证据台账，但不能锁定层级专属的第三章粒度、篇幅模板和验收规则。

## 2. 规范依据

- **N1-county**：《第三次全国土壤普查县级成果编制及验收导引》，国务院第三次全国土壤普查领导小组办公室组织编写，二〇二四年七月。[农业农村部公开 PDF](https://www.moa.gov.cn/ztzl/dscqgtrpc/zywj/202506/P020250620367048963194.pdf)。
- **N2-municipal**：《第三次全国土壤普查省市级成果清单及编制导引》。市级项目必须取得正式下发或项目确认的完整版本并记录文件标识、版本和适用依据；不能只根据网页摘要锁定细节。[鄂尔多斯市农牧局对该导引的正式引用](https://nmj.ordos.gov.cn/xwdt/bmdt/202607/t20260724_3910974.html)。

本技能依据用户提供的市级土壤志提纲页与N1-county公开全文建立下列差异基线。新版本、地方细则、合同或审定意见与基线不一致时，记录冲突并由有权责任方确认；不要静默拼接两套要求。

## 3. 核心差异

| 比较维度 | 市级土壤志 | 县级土壤志 | 编纂影响 |
|---|---|---|---|
| 成果形成方式 | 以所辖县级成果核验、汇总、接边和制图综合为重要基础 | 以本级调查、检测、制图、评价及历史资料为基础 | 市级必须建立“县级成果—市级结论”汇总追溯链 |
| 空间分析 | 突出县际差异、跨界一致性、市域分区和区域协同 | 突出县域内部土壤分布、利用差异和剖面支撑 | 市级表图至少保留行政单元比较维度，防止平均值掩盖差异 |
| 第三章上位单元 | 以土类为次一级标题，介绍其全部亚类 | 以亚类为次一级标题，逐个展开 | 章节样式和篇幅结构不能互换 |
| 第三章展开深度 | 土类→亚类→土属；土属记述分类与分布、性状、利用与改良 | 亚类→土属→土种；土种记述分类、分布、性状、利用性能与典型剖面 | 市级以土属为主要重复叙述单元；县级以土种为主要重复叙述单元 |
| 土种处理 | 通常由独立市级土种志系统承载，土壤志避免逐土种重复扩写 | N1-county要求在土壤志中覆盖下辖土属与土种，三普剖面土种附标准剖面照和景观照 | 市级不能为了“像县级”而复制整套逐土种正文 |
| 类型一致性 | 必须检查同土异名、同名异土、县际边界不连续和汇总遗漏 | 必须检查本县土种清单、剖面支撑和图志一致 | 市级新增跨县分类系统一致性门槛 |
| 评价利用 | 汇总所辖区域结果并表达市域差异、主导限制因素和分区利用 | 结合县域评价单元给出具体利用现状、问题与措施 | 市级不能只把县级数值简单相加，县级不能只写市级宏观判断 |
| 保护建议 | 对接市域农业发展目标，提出跨县布局、区域协同与分区治理 | 对接县域实际，提出具体障碍改良、耕地保护和可执行措施 | 建议必须与问题、证据、责任尺度匹配 |
| 配套图件 | 市域土壤类型图、关键属性图，重点检查县际接边和制图综合 | 县域土壤类型图、关键属性图，重点检查土种与剖面、图斑一致 | 图件来源、比例尺和综合过程分别留档 |

## 4. 共享六章骨架与差异化契约

两级提纲均可使用以下六章主骨架，但“标题相同”不等于内容粒度相同：

1. **区域概况**：市级应呈现市域整体及所辖区域差异；县级呈现本县（市、区、旗）自然、社会经济、土地利用与农业生产。
2. **土壤形成、分类与分布**：市级增加分类系统统一、县际接边和市域分布规律；县级突出县域成土过程、分类系统和图斑分布。
3. **土壤类型**：市级按“土类—亚类—土属”展开；县级按“亚类—土属—土种—典型剖面”展开。
4. **土壤理化性状**：市级同时呈现全市统计与县际异质性；县级按地类、土壤类型、成土环境和空间分布阐明属性规律。
5. **土壤资源评价与利用**：均包含利用现状与问题、耕地质量、专题适用性和改良保护；市级强调县级结果口径统一与市域综合，县级强调评价单元和本地落地。
6. **土壤资源利用与保护建议**：市级形成跨县协同和全市发展建议；县级形成对象、区域、措施、责任与预期作用明确的县域建议。

土特产品专题仍按适用性处理：`applicable_available`、`applicable_missing`、`not_applicable`、`unknown`四态分开。无报告不等于未开展；确认未开展或不适用后才可有据省略。

## 5. 自动识别规则

运行：

```text
python scripts/level_profile.py detect <任务书/导引/模板.docx或文本> [更多文件] --output <level-profile.json>
```

强市级信号包括“市级成果报告形成提纲”“省市级成果清单及编制导引”“核验所辖县级成果”“县际接边”“市级制图综合”。强县级信号包括正式标题“县级成果编制及验收导引”及稳定出现的“县（市、区、旗）”县级成果对象。标题中的“××市”只记为弱线索。

判定须满足两个条件：强信号达到门槛，且领先另一层级的分差达到门槛。两类强信号同时出现时，可能是市级文件引用县级成果，也可能是混装材料；识别器返回`unknown`或降低置信度，由人工依据文件角色裁决。不能通过删除冲突页强迫脚本给出想要的结果。

## 6. 市级新增质量门槛

- 所辖县级成果是否齐备，版本和验收状态是否明确；
- 土壤分类名称、代码、层级及上下级对应是否统一；
- 相邻县图斑是否接边，跨界土壤类型是否出现无依据突变；
- 面积汇总是否去重、不漏、闭合，市级总量与下级汇总差异是否解释；
- 县际指标是否同一地类、土层、时期、方法、单位和统计口径；
- 市级制图综合是否保留方法、参数、验证与不确定性记录；
- 市域结论是否同时说明总体格局、区域差异和异常县域；
- 市级土壤志与市级土种志是否分工清楚、互相引用且不矛盾。

这些门槛是市级成果的增量要求，不替代资料、证据、数值、篇幅和版面的一般门槛。
