# 编纂框架与章节契约

以市县级导引共有的六章为默认骨架。先按[levels](levels.md)确认成果层级：市级读取适用的省市级导引，县级读取N1。正式地方要求可细化或调整，但保留内容映射，不能为“通用”随意换掉必需内容。调查史可放前言或附录；历史变化主要嵌入相关主题，不必另立一章重复。

每章起草前填 [章节契约](../assets/project/section-contract.md)：目的、范围、来源、已知事实、必答问题、表图、允许/禁止判断、相邻章关系、缺口与验收。不是把合同字段写进正文。

## 前置部分

**功能**：说明编纂对象、断限、资料基础、组织及读法；不是再写一份工作报告。

输入：任务文件、工作报告、资料清单、实际编纂信息。成稿：封面、前言、目录、图表目录；编纂说明/凡例和人员表按项目需求安排。前言交代调查与编纂关系、基础数据与主要成果，不写未经确认的完成数量和应用成效。名称、行政代码、机构、日期与封底、页眉一致。

目录由真实标题生成；不把范例题注设成 heading。凡例可规定断限、地名、计量、分类体系、缺测符号和引用方式；批注/内部催补不进入凡例。

## 第一章 区域概况

**问题**：在什么区域和水热、母质、地形、植被、水资源及利用条件下，形成怎样的土壤背景？土地利用与农业生产怎样变化？

输入：总体/工作报告的可靠县情，类型/属性报告的环境资料，地类统计，年鉴、二普和历史档案。记录气候多年平均的统计年段及站点，不能把某一年的气象值当气候常年值。

结构：区位与范围 → 自然条件 → 社会经济中与土壤利用有关的内容 → 土地利用现状与历史 → 农业设施、耕作制度、投入产出及历史。每段围绕土壤关联取舍，避免大段交通区位宣传。

表图：区位/行政图、母质或地质图、地形图、土地利用图及分类面积表；气候表、农业/历史对照表按资料必要性选。不能从概况地图目测面积。

边界：面积/年份/地类口径清楚；土地利用与农业历史缺失留缺口，不能悄悄只写现状并标为全章完成。衔接第二章时提出已有材料支持的成土环境联系，不先断言过程强度。

## 第二章 土壤形成、分类与分布

**问题**：当地主要成土过程是什么？分类依据、类型数量与新旧关系是什么？空间分布有何规律？

输入：类型报告、审定分类表、新旧对照、剖面和环境资料、类型图及面积表。

写作：

- 形成：本地证据 → 对应发生过程 → 具体性状与分布表现。仅写当地有据的过程，不将所有教科书中的过程逐条安放。
- 分类：明确实际采用系统及版本，列土类—亚类—土属—土种、简名/连续命名和代码；中国发生分类与系统分类分别呈现，不能混成一棵层级树。
- 沿革：新老类型对应、合并/拆分/更名及原因，标明非一一对应；名称变化、误分订正、真实演变分开。
- 分布：按图、面积和环境联系概括水平/垂直或地貌分异，允许例外，不用少数点位推演全县连续梯度。

表图：分类表、新旧对应表、系统分类参比表、类型面积表与类型图；有资料才做剖面/地形序列示意。市级另检查所辖县分类名称与代码统一、相邻县图件接边和市级制图综合过程；县级检查土种、剖面与图斑一致。验收时分类清单、分布表图和第三章条目相互对照，缺一种就定位原因。方法限于解释结果所需，不复制制图报告全部操作步骤。

## 第三章 土壤类型

**功能**：志书核心资料章，但市县级的展开粒度不同。

- **市级**：以土类为次一级标题，介绍所有亚类；土类层写分布区域、类型特征、利用与改良和所辖亚类，再按亚类列出土属，重点写各土属的分类与分布、土壤性状、利用与改良。市级土种志独立承载的逐土种详述不在土壤志中机械重复。
- **县级**：依N1对全部亚类总体记述，并沿土属逐个土种记述，不能只选“主要土种”替代完整覆盖。

县级亚类层：分布区域、类型特征、利用与改良、所辖土属土种。先写共同特征，土种条目写区别，不循环重复相同母质常识。市级对应的土类层和亚类/土属条目也遵循“上位单元写共性、下位单元写差异”。

先从审定分类清单建立project.json的soil_inventory（来源、定位、应覆盖ID及确认状态），再逐行填写soil_types.csv。县级以土种ID做完整覆盖对照；市级以土属ID做土壤志正文覆盖对照，并另核市级土种志清单。简名/连续命名是同一分类单元的不同表达，不重复计数。若跨章调整条目，仍保留稳定ID和正文定位；不能通过删台账行隐藏未写分类单元。

没有三普剖面与没有土种记述依据不同：前者可采用有据的历史剖面或历史土种记述，后者是具体条目缺口。历史记述没有照片不等于需要补造剖面；明确来源年代和记述范围即可，不能冒充本次调查。剖面记录的照片、理化表和描述须按同一个编号匹配；多个真实剖面可分别列出，不拼接成一个虚构剖面。

县级每个土种使用[土种卡](../assets/project/soil-type-card.md)，至少覆盖：

1. **分类归属**：正式名/地方名/连续命名、代码，发生分类归属和有依据的系统分类参比；不能从土名猜土族。
2. **分布范围**：乡镇/地貌部位、土地利用、面积和来源；剖面采集地不等于土种全部分布。
3. **土壤性状**：母质、土体构型、发生层、障碍层、关键物理化学性质及性状变幅，区分多剖面综合范围与单剖面值。
4. **利用性能**：作物/耕作制度、适宜性与限制、土壤质量、实际产量及经验成效。没有产量资料不从作物常识生成产量数字。
5. **典型剖面**：来源年代、调查编号、位置与环境、采样日期、母质/植被/利用、层次深度、颜色及干湿状态、质地/结构/孔隙/根系/结核/边界等记录和理化表。

有三普剖面：标准剖面照+景观照，并核对照片编号、层位、描述和物化表。无三普剖面：按N1可用二普/其他历史调查补充，明确历史身份；不能从相邻土种借照片或把多剖面拼成一个真实剖面。历史也无记录时标记该条缺项，不造剖面、不替用户改变类型清单。

层深上界应小于下界，相邻层的重叠/缺段回查原始记录；不为好看强行等厚。土体构型、诊断特征、发生层名称与数据/照片对应；照片不经生成式填补、增强出不存在的层界。敏感定位按许可公开。

## 第四章 土壤理化性状

**问题**：目标区域总体怎样？哪些地类、土类或区域不同？有可靠历史变化吗？哪些性状限制利用？市级还必须说明县际差异和异常区域，不能只给全市平均值。

输入：数据分析、属性制图、相关专题及历史报告。覆盖物理、化学、有机质与氮磷钾、中微量、其他相关元素及属性关联；按适用指标和本地意义确定详略，不编造未测指标。

物理关注颗粒组成与粒径体系、质地、耕层/土层厚度、容重、团聚体；化学关注pH方法、CEC以及适用盐分/碳酸钙/交换性酸等；养分明确全量与有效态。没有独立有机质专题不妨碍据数据报告写有机质。

重点指标结构：范围与方法简述 → 样点总体和制图结果分别表达 → 地类差异 → 土类及相关环境差异 → 经H检查的历史变化 → 问题及利用含义。不是强制每项同样段数。

表图：带等级边界的样点/面积统计、分地类与土类表、属性图；历史表图仅在可比时给差值和变幅。给有效n；均值、中位数、极值、面积各讲其含义。正文挑关键差异，不逐格复述。

成因证据不足则保留描述性结论；不把均值跨分级边界说成全县所有土壤改变等级；单一元素提升不等于综合肥力提升。

## 第五章 土壤资源评价与利用

**问题**：现状利用与适宜性匹配吗？耕地等级与主要限制在哪里？已有何种改良保护经验？

输入：农业利用适宜性、耕地质量、退化障碍，适用的土特产及地方专题。各评价先锁定范围、标准版本、分类/等级和方法，不重新发明评价体系。

基本结构：土壤资源利用现状与问题 → 农业利用适宜性及匹配 → 耕地质量等级 → 适用的土特产评价 → 主要退化/障碍及改良利用保护。具体层级映射N1，不因重排丢任务。

表图：适宜类/程度及现状匹配表图、耕地等级面积与乡镇限制因素表图、主要障碍表；土特产只在适用时出对应评价表图。未开展专题可省略；保留适用性记录，不在正文堆“没有提供”字样。

质量边界：评价适宜面积不等于可开发后备耕地；高适宜产品区不等于产业可行性；酸性、酸化、盐渍化、侵蚀、污染需各自依据。无检测不能宣告安全。第六章建议可以引述本章结论，不能复制整段措施。

## 第六章 土壤资源利用与保护建议

**功能**：从目标区域实际问题提出有对象、条件和依据的技术/方向/目标/政策建议。市级突出跨县布局、区域协同和市域发展目标；县级突出县域可落地的障碍改良、耕地保护和实施措施。

每条建议 = 已确认问题与区域 → 适用土壤/地类/作物 → 建议动作 → 实施条件/约束 → 监测指标；有依据才列数量目标、剂量、工期和成效。引用对应E和前章表图作为工作记录，成稿用正常章节或图表引用。

可涉及耕地保护、产业布局、细碎化、灌排、肥料利用、耕作改良、培肥等，只选本地有证据的事项。区分已有成效、拟实施技术和政策建议。不给虚构预算、石灰用量或增产率；仅给方向时明确适用条件。

## 后置部分和篇幅

主要参考文献按N1著者—出版年制，中文在前按拼音排序，英文按字母顺序；逐项核验实际引用与书目信息。附图按N1；详表、样点/剖面索引、分类对应、术语或数据字典按需求附录化。目录、引用和附件标识同步。

市县级土壤志没有一个可替代内容质量的全国统一总字数。本技能必须按[模板驱动的篇幅契约](length.md)确定项目篇幅：先测同层级指定模板，再按层级对应的分类叙述单元、属性、评价模块和建议主题折算，锁定六章及全志目标和允许区间。不能为了更长复制专题报告，也不能为压缩篇幅漏记应覆盖的分类单元。
