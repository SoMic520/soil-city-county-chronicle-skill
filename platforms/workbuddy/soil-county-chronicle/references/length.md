# 模板驱动的篇幅契约

县级导引没有规定土壤志统一总字数，但本技能按用户要求必须建立项目篇幅契约。篇幅不是随意发挥：先以用户指定且确认适用的完整模板计量，再根据目标县真实内容规模折算，锁定总量和六章区间。达到字数不能替代资料、土种覆盖和专业质量。

## 1. 统一计量口径

默认指标为“接受修订后的章内叙述正文有效字符数”：每个Unicode字母或数字计1，不计空白和标点。排除封面、前言、目录、标题段、表格内文字、图表题注、页眉页脚、附件、脚注尾注及删除/移出修订文字。表格和图件数量另记，不能用表内数字把正文篇幅做大。

模板、阶段稿和终稿必须用同一measurement_version。运行：

```text
python scripts/length_profile.py measure-docx <模板.docx>
python scripts/length_profile.py measure-docx <终稿.docx>
python scripts/length_profile.py calculate-plan <length-plan.json> --output <待复核计划.json>
python scripts/length_profile.py check-plan <length-plan.json>
python scripts/length_profile.py check-plan <length-plan.json> --final
```

脚本按标题1识别六章；不是六章、章标题样式错误、正文大量放在表格或文本框时会给出限制或警告，须人工重建对应关系。脚本不接受DOC改名伪装DOCX，不评价内容真假。

## 2. 模板选择和基线

优先次序：项目正式指定/通过验收的同类县级模板；同省同类型且确认可比的合格县级模板；本技能现有邵东样稿仅作无更高优先模板时的初始参照。模板的文件名、路径、SHA-256、适用依据和计量输出必须留档。样稿有内容或样式缺陷仍需另行审查，篇幅相近不等于照抄事实或保留缺陷。

本技能开发时只读计量邵东修复版，SHA-256为`8d466b60cfd8503e286fdad19998389c3c770c6fb5fe861419ace6a12349321a`。按上述口径得到：

| 章 | 模板有效字符 | 结构规模相同时的默认允许区间（目标±15%） |
|---|---:|---:|
| 第一章 区域概况 | 13,139 | 11,168—15,110 |
| 第二章 土壤形成、分类与分布 | 16,459 | 13,990—18,928 |
| 第三章 土壤类型 | 117,003 | 99,452—134,554 |
| 第四章 土壤理化性状 | 30,187 | 25,658—34,716 |
| 第五章 土壤资源评价与利用 | 25,295 | 21,500—29,090 |
| 第六章 土壤资源利用与保护建议 | 24,260 | 20,621—27,899 |
| 六章合计 | 226,343 | 203,708—248,978（全志目标±10%） |

上述是当前样稿基线，不是全国法定字数。具体县结构规模不同，第三至六章按下一节折算，不能硬凑22.63万字。

## 3. 自适应折算与“不差太多”门槛

第一、二章通常不随土种数线性变化，目标值须在模板对应章±15%内。第三至六章先在模板副本或结构清单中逐段标注“固定叙述”和“重复结构单元”，再按模板的实测密度折算：

`本县章原始折算值 = 模板固定叙述字符数 + (模板章值-模板固定叙述字符数) ÷ 模板结构单元数 × 本县结构单元数`

第三章结构单元为经审定的土种数；第四章为实际纳入分析的属性指标数；第五章为实际适用且有成果支撑的评价、退化或障碍模块数；第六章为从前章证据导出的建议主题数。模板固定叙述字符数、重复单元范围和计数须在template_structure_evidence定位；模板和本县须用相同计数定义并在project_structure.basis定位清单，不能拆细或合并名称来操纵预算。没有完成标注和复核时，对应章不能锁定篇幅。

为防止差距失控，第三至六章的原始折算值先限制在模板章值的70%—130%，目标值再按该受限折算值确定，并且仍不得超过模板章值±30%；目标值与受限折算值的差异不得超过±10%。六章目标合计不得偏离模板合计±20%。每章实际值必须在锁定目标±15%，六章实际合计必须在六章目标合计±10%，且终稿六章合计不得偏离模板合计±25%。整数边界分别下取整、上取整。上述百分比是本技能为落实“自适应但不能差太多”设置的项目控制线，不冒充国家统一字数规定。

土种、属性或专题缺资料时不通过删减结构数来压低目标：按审定应覆盖数登记，缺口另记。未开展且有依据不适用的土特产专题不计入第五章模块；仅未提供报告不能当作0。第三章不能因篇幅上限删土种，必要时将详表放附录，但每个土种正文的分类、分布、性状、利用和剖面要求仍须覆盖。

## 4. 锁定、偏差与裁决

在章节起草前完成模板计量、结构计数、目标/上下限及适配依据，status改为locked。`calculate-plan`可在结构字段完整后生成默认目标和区间，输出不覆盖原文件且状态保持planning；人工核对模板可比性、标注范围、结构清单和正式要求后才能锁定。阶段稿每章完成后回填actual；终稿用同一脚本重测。超界时必须先判断：遗漏内容、重复专题报告、表格误计正文、结构数变化或地方正式要求；纠正原因后重新计量，不用空话扩字或机械删句。

合同、地方验收文件或经项目责任方书面确认的显著结构差异有明确字数/页数或例外处理时优先。把来源、定位、统一计量口径、责任方确认和处理结果填入formal_override，并按确认要求调整各章目标；启用有效例外后可不受模板距离、结构密度和模板合计限制，但各章目标±15%和全志目标±10%的成稿控制仍执行。页数要求须先按本计划口径换算，不能直接把“页”混作有效字符。不同正式要求互相冲突时登记conflicts并取得有权责任方裁决。不得把单个采购合同或邵东样稿的数字冒充全国统一要求。

终稿门槛：模板身份与哈希可追溯；结构计数有清单；六章目标、范围及实际数完整；全志合计正确；每章和全志均在允许区间；偏差原因已关闭；计量结果与最终交付DOCX哈希对应。
