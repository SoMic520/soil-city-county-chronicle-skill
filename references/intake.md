# 前期资料：报告优先的接收与可写性判断

## 先接收，再判断缺什么

1. 明确县级行政对象、编纂断限、成果用途、指定规范、交付格式、已有志稿状态和项目指定/可比的完整县级模板。已知的不用反复询问。
2. 建资料目录与来源ID，保留原文件。区分报告成稿、修订稿、审定稿、扫描件、单独图件和仅文件名；不按“最终版”“0819”字样自动裁决版本。
3. 先提取目录、编写依据、资料来源、统计口径、结论、表图、附录、质控与审定说明。DOCX 表格和图中文字不能因普通文本提取遗漏而被当成不存在。
4. 复核OCR易错的负号、上下标、单位、数字、等级边界及合并表头；关键数据回到原页。照片、图例、剖面层界必须看原图。
5. 按“章节需回答什么—已有哪处证据—还有什么具体缺口”登记，不先生成长篇正文再找引用；同步计量模板并登记土种、指标、评价模块和建议主题清单，为篇幅契约提供同口径结构数。

### 现有报告到土壤志的映射

| 常见报告 | 优先提取 | 进入土壤志 | 重点核对 |
|---|---|---|---|
| 总体报告 | 县情、任务、核心结果、成果清单 | 前言和全志摘要线索 | 摘要数值回到专题详表；不作为所有结论唯一来源 |
| 工作报告 | 调查时间、范围、队伍、样点类别、QC/验收与调查史 | 前言、简述方法、附录/调查沿革 | 点、样品、检测项次分开；有无实际验收依据 |
| 类型汇总/类型图编制报告 | 分类表、版本、新旧对应、类型面积、分布、剖面、照片 | 第二、三章与附图 | 土类—亚类—土属—土种完整性；图、表、条目一致 |
| 属性图编制技术报告 | 制图范围/土层/方法、分级面积、空间格局、验证 | 第四章和附图 | 不把预测结果叫实测；有无独立验证及适用尺度 |
| 数据分析/数据报告 | 有效样本、指标定义、检测方法、统计量、分组、字典 | 各章共用口径，第四章 | 全量/有效态、样点/面积、分母、缺失值 |
| 退化与障碍报告 | 本地类型、程度、分布、依据、因果证据和改良 | 第五章，必要时第四章 | 酸性不等于酸化；障碍面积不等于治理面积 |
| 耕地质量等级评价 | 评价范围、方法、等级面积、限制因子、验证 | 第五章 | 只覆盖实际评价耕地；不能泛化为所有土壤质量 |
| 农业利用适宜性评价 | 评价对象、标准版本、类/程度、现状匹配、限制因子 | 第五、六章 | 适宜不等于允许开发；当前规范与报告方法是否相容 |
| 特色农产品/土特产适宜性评价 | 产品、调查范围、评价依据、土壤及气候条件、图和验证 | 第五章条件节，必要时第六章 | 是否开展且适用；不拿品牌介绍替代评价 |
| 酸化地专题 | 时期、pH方法/土层、比较基础、等级与区域、治理证据 | 第四章历史变化、第五章障碍 | 单次低pH不能产生酸化速度和面积 |
| 有机质专题 | 方法、样本与制图结果、空间差异、历史变化 | 第四章，建议依据 | 有机质不是有机碳；浓度不是储量 |

同一表反复出现，指定一个“结果主来源”，其他报告为交叉核验，不能把转引当独立重复证据。文件名提到“去重金属”“含附图”等，须读内容确认，不能据文件名推断合法删项。

## 专题适用性四态

| 状态 | 条件 | 工作动作 |
|---|---|---|
| applicable_available | 本项目适用且材料已取得 | 还要审查内容和质量，不能仅凭有文件就写 |
| applicable_missing | 适用/任务明确要求，但所需证据缺失 | 记录影响范围和最小补件；其他章节继续 |
| not_applicable | 正式任务、可靠资料或用户明确确认不开展/不适用 | 记录依据；N1允许未开展土特产节省略；不凭此写“本县无此产品” |
| unknown | 只有截图未见该文件、任务含糊、是否调查不明 | 问具体“是否开展该专题”，同时推进有依据部分 |

酸化、盐碱、侵蚀、黑土、有机质专门调查等也先判适用性，不能照搬样稿设置全部专题。不过：**没有专题报告不等于无需记述已有数据能证实的当地问题**。有机质常规属性可由数据/属性报告支撑，不要求另交有机质专题报告。

条件专题状态不是删除基本章的通行证；N1要求的土种、理化性状、历史内容缺失须登记，不擅自判“不适用”。当地任务明确规定做某专题而材料称未开展，登记冲突，不能只按用户口头略过验收义务。

## 补充资料按用途分级

| 资料 | 何时成为必要补件 | 可以先从哪里找 | 缺失影响 |
|---|---|---|---|
| 任务、验收、审定意见及规范 | 规范/版本/范围不明或正式交付 | 报告编制依据、附录、项目通知 | 定稿依据未锁定 |
| 县界、地类与基准期 | 面积冲突或跨期比较 | 报告底图说明、数据来源和统计表 | 受影响面积、变化、匹配结论 |
| 气候、母质、地形、水文、植被 | 报告缺字段或解释无依据 | 县志、统计年鉴、气象/自然资源等官方资料 | 相应背景和成因；不阻止其他事实 |
| 土地利用、农业生产历史资料 | 需要历史变化而报告不载 | 二普、历次国土调查、历年统计和地方档案 | 历史覆盖，不能编造变化 |
| 样点/剖面原始记录、检测/QC | 土种支撑、数值矛盾、方法/层次不清、需新计算 | 已有类型/数据报告附表、合格记录和照片 | 对应土种或指标，不一律卡住全部写作 |
| 类型图/属性图源文件及面积表 | 插图不可读、范围不明、需核算面积 | 报告高清附图、审定导出图/表优先 | 图件及空间统计；无权据图目测面积 |
| 分类字典与新旧对应 | 类型名、归属、数量冲突 | 审定分类表和类型报告 | 第二、三章受影响条目 |
| 评价数据库、GIS模型资料 | 用户要求重算或报告无法解释关键冲突 | 先请求相关导出表和方法，不默认全库 | 新评价不属于简单写志；需单列范围 |
| 图照授权、涉密与公开边界 | 对外发布或含敏感定位资料 | 数据管理与授权文件 | 发布/展示权限，不擅自外传原数据 |

## 第一阶段应交付

资料台账、规范采纳表、模板计量与结构清单、六章材料覆盖表、专题四态表、关键口径清单、最小补件清单和下一步。明确：现在能写哪些小节、哪些只能列结构、哪些结论暂不能写。尚未取得适用模板时可继续资料整理，但不得锁定全志篇幅或称已具备完整起草条件。

若当前只有截图：按实际可辨认文件登记；名称不全就保留缺字或仅登记类别，不预设报告数量。说明未读全文，先给针对性接收清单，请用户提供所在文件夹或报告文件；可建立通用模板，不能开始县域事实性正文。通用技能开发则无需等待这些县级报告，使用匿名合成情景测试即可。

## 把资料状态落实到可操作记录

用requirements.csv登记“需要覆盖的内容”，sources.csv登记“已收到的资料”，gaps.csv登记“具体缺什么”；这三件事不能互相替代。要求可以由一份报告多处支撑，也可以由多份报告共同支撑，不按文件数量判材料齐全。

每个缺口说明：受影响的requirement/章/主张、先检查的现有报告、最低限度需补的页表/图件/方法/审定说明、责任方和完成状态。条件专题确认不适用后关闭该专题补件，不把常规属性内容一起删除。台账是本技能的工作工具，不宣称属于全国法定交付清单。
