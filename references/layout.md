# 三普基准对齐的县级土壤志排版与交付

## 0. 依据及执行优先级

本文件为土壤志DOCX创建、重排、修订和排版终检的必读要求，不是可任选的美化建议。用户已指定以soil-third-survey-report的《土壤三普专业报告强制排版基准》为可靠基准，本文件将其通用排版规则自包含地落实到土壤志。未安装原skill也能执行；不得用软件默认、旧镜像页边距或模型习惯替换。

依据标识：N1-format＝2024年7月县级导引《成果报告撰写格式要求》，印刷85页，见[sources](sources.md)；SFORMAT＝三普skill的references/report-format-requirements.md，2026-09-04本次读取版本。N1明确的字号、字体、行距、编号、显示精度等优先；SFORMAT补充缩进、粗体开关、页码、图表空行、表格等具体执行规则。用户/地方正式模板的具体例外逐项记录，不把整套基准降成建议。

必须保留的区别：

- **标题**严格按N1；可以使用“第一章、第二章……”并对应Heading 1，不再把“一、”误作章标题。
- **目录深度**：N1规定按具体情况采用一级或二级。保留SFORMAT真实目录和样式完整性要求，但不把其“覆盖所有实际使用层级”机械扩成五层目录。toc_semantic_levels用有序数组选择：["chapter"]仅章，或["chapter","level_1"]收录章及“一、”；空数组表示待确认。禁止自由文字、跳级或重复角色。只核对选定层级是否漏项，正文其他合法层级仍保留真实样式。正式地方要求另定深度时，须为county_requirements.toc_max_depth逐字段登记有效依据和责任方确认，并从chapter起连续选择对应角色，不能只改说明文字绕过N1。
- **精度**：SFORMAT本身允许正式导引优先。县级土壤属性按N1一般1位、砂粉黏等可整数，亩整数、万亩2位；没有更具体要求的其他小数沿用SFORMAT的2位规则，不能增加虚假精度。
- **普通上下页边距**按SFORMAT专项基准第1节的2.54厘米。原skill摘要/红线流程另有“页顶距1.5、页底距1.75”表述，本技能不把这组数混入普通上下页边距，也不擅自解释成页眉页脚参数。页眉距顶、页脚距底按项目模板独立登记。
- SFORMAT中的Logo8.15磅只对采用该封面参照设置的Logo段有效；指定附图保护只作用于用户实际指定对象，不能写死某一县Logo或某一组图号。

先按[layout.json](../assets/project/layout.json)锁定排版计划，再实施。styles/execution是已采纳基准，county_requirements是土壤志要求；这些不都等于全国强制条款。adoption_confirmed表示本项目已核对适用性，不表示条款可随意选择。

## 1. 页面、封面和页码

普通正文A4纵向：上、下各25.4 mm，左、右各31.8 mm；不默认镜像页边距。附图、横向大图/宽表和已确认的特殊分节，按正式模板或原稿规定保留几何参数，逐节记录方向、纸张、pgMar和适用范围，禁止对整篇盲目批量套用普通页面参数。

封面白色，胶装、双面打印；厚度适宜时含书脊信息。封面不使用标题样式或大纲级别、不进目录、不显示页码，文字无首行缩进。已有合格参照时保留元素顺序、尺寸和垂直位置；无参照时信息项之间仅一个空行。Logo如存在，采用嵌入型、段落居中、左右及首行缩进0，Logo段单倍行距，不擅自缩放。只有采用相应参照设置时，Logo段前后各8.15 pt；不能给所有县新增Logo或将该段行距扩散至整个封面。

前言、目录等前置部分使用连续大写罗马页码；正文另起页并从阿拉伯数字1开始。用分节及真实PAGE字段实现，不手打页码。页码五号Times New Roman、页脚居中、无首行缩进、段前后0。封面、前置、正文以及特殊页面的页眉页脚链接关系逐节核对，不能让封面取消页码波及正文。

Word/WPS中经用户确认正确的封面，不因LibreOffice单独渲染漂移而删空段、移动落款或缩放Logo；记录兼容性差异，以目标软件确认版式，并继续核查对象/字段及其余全部页面。

## 2. 严格标题样式表

| 正文语义/编号 | Word样式/大纲级别（从0起） | 中文字体、字号 | 粗体 | 对齐、首行缩进 |
|---|---|---|---|---|
| 第一章、第二章…… | Heading 1 / 0 | 小二号宋体，18 pt | 是 | 居中，0字符 |
| 一、二、…… | Heading 2 / 1 | 三号黑体，16 pt | 否 | 左对齐，2字符 |
| （一）（二）…… | Heading 3 / 2 | 四号宋体，14 pt | 是 | 左对齐，2字符 |
| 1. 2. …… | Heading 4 / 3 | 小四号黑体，12 pt | 否 | 左对齐，2字符 |
| （1）（2）…… | Heading 5 / 4 | 小四号宋体，12 pt | 是 | 左对齐，2字符 |

字号、字体及加粗章标题居中来自N1；样式映射、首行缩进和黑体显式不加粗按SFORMAT执行。数字、西文一律Times New Roman。所有标题段前、段后各0.5行，左右缩进0，不统一替换为6 pt。检查直接格式和样式继承，不以肉眼觉得相似判定合格。

Heading 1—5是语义角色，对应中文版Word“标题1—5”；实施时查实际样式ID、大纲级别和编号绑定，不因软件本地化名称不同新建重复样式。

“1.”与标题文字之间一个半角空格；同上级内编号连续，多级编号绑定正确标题样式，章序可以实际生成“第一章”。不手工重复输入自动章号。Heading 1只放章标题；N1原则上不出现的“五级标题”指章下第五级，不是禁止Word Heading 5。只启用实际需要层级，不机械增设下级标题，不改变用户明确要求保留的标题文字和编号。

“前言”“目录”按Heading 2层级、三号黑体不额外加粗，但逐段居中、首行0、不接正文“一、”编号，不修改整套Heading 2的左对齐规则；图目录、表目录标题同样无首行缩进。用局部覆盖或明确依赖的前置专用样式承载例外，禁止让目录自收录、封面混入目录或为绕过问题把正文真标题改成普通段落。

## 3. 正文、字体、单位和数值

正文小四号宋体，首行2字符，左右缩进0，单倍行距，段前后0。原有、确有承接功能的帽段保留正文格式，不凭空增加空泛总结；不将报告每段至少300字等篇幅规则套入土种条目。

全部Word文字为黑色，所有英文字母及阿拉伯数字含标题、目录、表格、题注、页码和上下标均为Times New Roman；不额外加粗黑体。审阅标记的显示颜色不属于正文颜色，不改掉修订记录；地图图例、科学照片和图内专业色标不得因此改黑或重绘。

封面、章标题、题注、页码、图片段、表内文字和目录条目无首行缩进；标题2—5的正文层级仍首行2字符，前置居中标题单独例外。清除直接格式及样式中的firstLine/firstLineChars，目录更新后复查。

带圈序号后一个半角空格，不另加顿号。计量单位按项目标准用规范符号；正确设置km²、g/cm³、NH₄⁺-N、Ca²⁺等上下标，不擅自把标准指定斜线形式换成指数形式。保留表头、同列、区间两端、正文和图中同一数值的一致精度及末尾0。用未修约原值计算/分级，不反向凑平合计；修约方法保存在编辑记录，原件数据不改。

## 4. 自动目录、题注和交叉引用

必须有可更新的正文目录及分别提取的图目录、表目录。正文目录按已确认的N1语义层级生成；图、表用独立标签/SEQ序列提取，不因共用“题注”样式而混成一个清单。不手打页码、点引线或图表序号。

图表题注使用“题注”样式：五号黑体10.5 pt、不加粗；数字/西文五号Times New Roman，黑色、居中、首行0、单倍行距、段前后0。序号后一个半角空格。表题在表上、图题在图下，是本技能执行要求，不再写成可选惯例。

图表按实际章号各自连续编号；章号来自对应章标题编号或正式模板，不固定为某章，不共用序列。正文用真实书签和REF/PAGEREF等交叉引用。移动、增删图表或标题后实际更新全部字段，不能只设updateFields=true。分别核对显示修订状态和拟接受后的逻辑结果，不擅自接受用户已有修订。

## 5. 图表说明段、空行与分页

顺序固定：**说明段 → 一个空白段落 → 完整图表块 → 一个空白段落 → 后续正文**。空一行必须是真正一个空白段落，不用段前后间距替代、不连续堆多个空段。连续两幅图或两张表之间只共用一个空行，不把前后规则叠成两个。

说明段在对象之前，图号/表号嵌入第一条实质性结果句，通常在该句末；首句仅说明范围或方法时放随后首条结果句。不把“见表×”单独成段，不在说明段与对应对象之间插入无关文字。

图形块＝图片＋图题＋全部图注；表格块＝表题＋表格＋全部表注。尾部空行在最后一条注释之后；无注时在图题/表格之后。题注不能孤立页尾，图注/表注不能错配另一对象。对象内部保持对应，但不能为强求说明段和大图同页，把二者整块推走造成大片空白。

大图可在紧随说明段的下一自然页开始；长表自然跨页并重复完整表头，不能把整张长表强行同页。先清除错误分页符、段前分页、与下段同页、段中不分页、对象锚点及环绕距离，再在同小节、同分析对象内调整说明段和图表块位置；不跨小节调走或让图表远离分析数页。附图另页起排造成的合理末页留白不强行填满。

## 6. 图片和表格

正文图片水平居中，段落左右及首行缩进0，保持比例，不拉伸、裁切、压坏图例或降低科学细节清晰度。用户实际指定不动的图，其内容、尺寸和页面布局均保留。土种照片核对编号、层界和来源，不用生成式工具补造性状。

表格按当前节的版心100%宽度“根据窗口自动调整”，整体居中、左缩进0。中文五号字体按合格模板统一并登记，所有数字/西文Times New Roman。表内无首行缩进、单倍行距、段前后0，不固定行高、不留多余空段空行、表和表题无底纹。表头加粗，普通表内文字不批量加粗，确有专业含义的强调保留依据。

跨页重复完整表头及单位；黑色单实线边框，不另强制特殊磅值，清除表格/行/单元格重复叠加粗线。长行不允许截断文字，必要时允许分割；宽表采用经确认的横向节或分表，在对应版心仍按100%，不缩到难读。续表保留原表号和续表标识，不重新编号。修改后逐表核对合并单元格、列头与数据对应、单位、边框及跨页线条。

类型图与关键属性附图按N1采用A3彩色折页；不把所有正文图改成A3。核对范围、行政界线、图例阈值、比例尺、必要方向/坐标说明、地名及来源；dpi与地面分辨率分开。原图保留，敏感定位依权限公开。

## 7. 实施、样式清理和真实终检

1. 先记录原件与工作副本、分节方向/纸张/边距、标题清单、样式/编号、表格、媒体、域、书签、对象、批注和修订基线。超大DOCX先只读ZIP/XML，不为排版重存原件；旧DOC更名不等于转换。
2. 先完成layout配置和逐项例外，再修改工作副本。授权修订时保留真实插入/删除/属性修订及批注锚点；新写不强制红线模式。内容、结构、版面三轮分别检查。
3. 样式清理前查使用情况和basedOn、next、link依赖。保留正在使用及被依赖的脚注、目录、题注、超链接、页眉页脚、表格、修订和对象样式；只删确认无用的冗余样式，或隐藏未使用内置样式，不为缩短列表破坏功能。前置标题的明确例外不等于随意复制“标题2新”等近似样式。
4. 使用用户指定软件实际打开、更新目录/题注/引用/页码，另存、关闭、等待写入完成、重新打开。用户指定LibreOffice时必须用该软件，不用“写了XML”冒充软件保存。没有指定时确认交付目标Word/WPS/LibreOffice并记录版本；软件安装、云上传不因调用技能自动获得授权。
5. 创建/修改DOCX时读取环境中可用的文档技能；本次仅更新skill不需要安装或启动Office。工具缺失或失败可交结构/工作稿及限制，不标排版终稿。
6. 同一最终版本渲染为PDF及逐页图，记录文件哈希、页数、检查人、每页范围与结果。先用联系表看整体，再原尺寸查看密集表、地图、剖面、目录、分节转折和异常页；联系表不能证明小字清晰。不得抽查后声称全页通过。
7. 全页检查缺字、字体替换、上下标、颜色、缩进、孤立标题、截表、表头重复、图表错配、题注/注释分离、空行、大面积空白、页码跳变及错误引用。与基线比正文、表格、对象、样式、批注锚点和修订；局部变更后至少回归受影响章及后续分页/字段。

## 8. 配置检查、例外和升级

运行python scripts/chronicle.py layout-check <layout.json>检查计划；正式交付用--final，全志check --final也会调用同一检查。它检查所填配置及人工记录，不读取DOCX版面，不以返回0证明样式已经落入文件。

styles、execution、county_requirements内的基准值不能静默修改。确有项目/地方要求时，修改实际采用值并在project_overrides_with_basis逐叶字段登记path（点分路径）、value（与实际值一致）、scope、basis、confirmed_by、confirmed=true；不能只写一句“模板特殊”。全局参数变更scope写global；仅某节/某对象保留例外，在preserved_sections_and_objects记录id、kind、basis、geometry_locator、review_evidence，不改变普通全局基准。

format_checks中的12项终检逐项填passed及实际检查定位，不能仅总开关done；没有指定保护对象时protected_objects可not_applicable并说明。未完成的保持pending。旧layout无新版schema时允许继续整理资料，但正式排版/终稿检查要求升级；备份旧配置、移入新版、逐项保留项目约定并记录差异，禁止覆盖未读取的用户设置或自动填写通过状态。
